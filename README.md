# 🧮 Calculator

A simple and responsive Calculator built using **HTML**, **CSS**, and **JavaScript**. This web application performs basic mathematical operations with a clean and user-friendly interface.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧮 Basic mathematical calculations
- 🧹 Clear (AC) button
- ⌫ Delete (DEL) button
- 📱 Responsive design
- ⚡ Fast and accurate calculations
- 💻 Easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript 

## 📂 Project Structure

```
Calculator/
│── index.html

│── script.js
│── LICENSE
```

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Saniya2020225/Calculator.git
   ```

2. Open the project folder.

3. Double-click `index.html` or open it in your preferred web browser.
